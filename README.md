# BXL Trade

เว็บไซต์จำลองเทรดราคาแบบ Candlestick รองรับมือถือ

## ฟีเจอร์
- Buy และ Sell พร้อมนับถอยหลัง 10 วินาที
- คำนวณผลกำไร/ขาดทุนจำลองเมื่อหมดเวลา 10 วินาที
- ปรับสีกราฟและซูมเข้า/ออก
- ใช้ข้อมูลจำลอง ไม่มีการเชื่อมต่อเงินจริง

เปิดเว็บได้จาก GitHub Pages หลังเปิดใช้งาน Pages จาก Settings > Pages โดยเลือก Branch `main` และโฟลเดอร์ `/ (root)`
